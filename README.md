# Exotic Car Hire KZN website

Promotional website for Exotic Car Hire KZN. No booking, just the fleet, the personalised plates and contact details.

## Put it online (GitHub Pages)
1. Upload everything in this folder (index.html and the images folder) to a public repository.
2. Go to Settings, then Pages, choose the main branch and the root folder, then Save.
3. Your site appears at https://YOUR-USERNAME.github.io/REPOSITORY-NAME/

## Editing
- Phone number: search index.html for 27837252146 (WhatsApp links) and 083 725 2146 (shown number).
- Cars and captions: edit the COLL list near the bottom of index.html.
- Photos: replace files in the images folder and keep the same file names.
